# Geek Informatic

Інтерактивні вебквести, ігри та ребуси з інформатики для уроків (1–11 класи). Статичний сайт для GitHub Pages: без збірки й без npm, лише HTML, CSS і JavaScript.

Живий сайт: https://otianoleksij.github.io/geek-informatic/

## Активності

| Назва | Тип | Клас | Тека | Файли |
|---|---|---|---|---|
| Агенти КіберЩиту | вебквест (кібербезпека, 8 місій) | 6 | `web-quests/agenty-kibershchytu/` | усе в одному `index.html` |
| Код Галактики | вебквест (блочне програмування, 15 рівнів) | 7 | `web-quests/kod-galaktyky/` | ядро `galaxy-core.js`, інтерфейс `app.js` + `index.html`, дані `levels.js` |
| Я керую роботом! | гра (стрілки й повтори, 10 рівнів) | 3–4 | `robot/` | ядро `robot-core.js`, інтерфейс `app.js` + `index.html`, дані `levels.js` |
| Марсохід у лабіринті | гра (алгоритм правої руки) | — | `mars/` | ядро `mars-core.js`, інтерфейс `app.js` + `index.html`; даних-файлу немає |
| 100 ребусів з інформатики | ребуси | 1–11 | `rebusy/` | ядро `rebus-core.js`, інтерфейс `app.js` + `index.html`, дані `rebuses.js` |

Ядро (`*-core.js`) не залежить від DOM і працює і в браузері, і в Node, тому його використовують валідатори з `tools/`.

## Структура репозиторію

```

  og/                              PNG 1200x630 для соцмереж (home, robot, mars, rebusy, ...)
vendor/                            сторонні бібліотеки (Blockly), див. vendor/README.md

  agenty-kibershchytu/index.html
  kod-galaktyky/                   index.html, app.js, galaxy-core.js, levels.js
```

## Запуск локально

У корені репозиторію:

```
python3 -m http.server
```

і відкрий http://localhost:8000/. Відкривати `index.html` просто з диска (`file://`) не рекомендується: відносні посилання між сторінками й сховище браузера поводяться інакше, ніж на справжньому сайті.

## Перевірка контенту

Потрібен лише Node.js. Запускай з кореня після будь-якої зміни рівнів, ребусів чи ядра:

| Команда | Що перевіряє |
|---|---|
| `node tools/check-robot.js` | рівно 10 рівнів робота: поля й символи, один старт і кристали, розв'язок справді виграє, `par` дорівнює числу блоків розв'язку, `maxBlocks` не менший за розв'язок (а для рівнів із повторами менший за мінімум ходів) |
| `node tools/check-galaxy.js` | рівно 15 рівнів «Коду Галактики»: квадратна карта 6..9, `start.dir`, `allowed`/`limits`, розв'язок виграє, `par` і `maxBlocks`, мінімальна вартість програми |
| `node tools/check-rebuses.js` | рівно 100 ребусів (по 25 у групах 1-4, 5-6, 7-9, 10-11): унікальні `id` і відповіді, відповідь збігається з обчисленою з `parts`, підказка не містить кореня відповіді й не довша за 120 символів, 2–4 частини, є картинка |
| `node tools/check-mars.js` | генератор лабіринтів (500 зерен): симетрія стін і зовнішня рамка, досяжність усіх клітинок, детермінованість генератора, різноманітність лабіринтів, що алгоритм правої й лівої руки проходить усі 500 лабіринтів, а наївна програма ні, спрацювання удару й ліміту кроків |

Кожна команда завершується кодом 0 і рядком `OK`, або виводить список помилок і завершується з кодом 1.

## Як додати рівень або ребус

Кількість рівнів і ребусів жорстко задана валідаторами (10, 15, 100). Якщо змінюєш кількість, онови відповідну перевірку й тексти на сторінках.

**Робот** (`robot/levels.js`). Поля рівня: `n` (номер підряд), `title`, `tip`, `map` (масив рядків: `S` старт, `G` кристал, `#` камінь, `.` порожньо), `maxBlocks`, `par`, `loops` (boolean), `solution` (команди `"R"`, `"L"`, `"U"`, `"D"` та повтори `{rep:N, body:[...]}`, N від 2 до 5, без вкладених повторів). Приклад: `{ n: 1, title: "Перший крок", tip: "...", map: ["S...G"], maxBlocks: 6, par: 4, loops: false, solution: ["R","R","R","R"] }`.

**Код Галактики** (`web-quests/kod-galaktyky/levels.js`). Поля: `n`, `title`, `story`, `tip`, `size` (6..9, дорівнює стороні квадратної `map`), `map` (`S` старт, `*` кристал, `#` астероїд, `.` порожньо), `start: { dir: "E"|"N"|"W"|"S" }`, `maxBlocks`, `par`, `allowed` (з `F L R C rep`), `limits` (наприклад `{F:2}`, може бути `{}`), `solution` (еталон; повтор через `rep(n, [...])`).

**Ребуси** (`rebusy/rebuses.js`, масив `window.REBUSES`). Поля: `id` (`r001`...), `g` (група `"1-4"`, `"5-6"`, `"7-9"`, `"10-11"`), `answer` (великі українські літери), `hint`, `parts` (2–4 частини). Частина: `{t:"А"}` (звичайні літери, можна `x:[позиції]` для викреслення), `{pic:"🐭", w:"МИША", ...}` (один емодзі і слово) або `{num:"1", w:"..."}`. Операції над словом `w` виконуються в порядку `rev` -> `keep` -> `rep` -> `l`/`r` (`keep` не поєднується з `l`/`r`; `rep:[["Ж","Ф"]]` замінює літеру). Приклад: `{ id:"r001", g:"1-4", answer:"МИША", hint:"...", parts:[{pic:"🐭",w:"МИША",r:1},{t:"А"}] }`. Додавай без повторів відповіді.

**Марсохід**: рівнів у файлі немає, лабіринт щоразу генерується із зерна (`MarsCore.generate`).

Після змін обов'язково запусти відповідний `node tools/check-….js`.

## Як додати нову активність

1. Створи теку (для гри в корені, як `robot/`, для квесту в `web-quests/<назва-латиницею>/`) з `index.html`.
2. Додай посилання «На головну» з відносним шляхом до кореня: `href="../"` для сторінки в `robot/`, `mars/`, `rebusy/`, і `href="../../"` для `web-quests/<назва>/`.
3. Задай `<title>` у форматі «Назва — Geek Informatic» і `<meta name="description" content="...">`.
4. На головній `index.html` скопіюй наявний блок `<a class="book bN" href="...">` у потрібну секцію (Вебквести, Ігри, Ребуси) і зміни клас, назву, опис та `href`.
5. Не підключай зовнішні бібліотеки й сервери без потреби: шрифти беруться з `assets/fonts/fonts.css`, бібліотеки лежать у `vendor/`. У `<head>` додай `canonical`, Open Graph, JSON-LD (див. розділ «SEO»), створи `assets/og/<slug>.png` і додай адресу в `sitemap.xml`. Також додай активність у список на `404.html`.
6. Якщо є рівні чи дані, винеси логіку в `*-core.js` без DOM і додай валідатор у `tools/`.

## Приватність

- Прогрес зберігається лише в `localStorage` браузера учня; ключі: `kiberquest-v3` (КіберЩит), `geek-galaxy-v2`, `geek-robot-v1`, `geek-mars-v1`, `geek-rebus-solved-v1`. Сервера й облікових записів немає, кожен бачить лише свій прогрес.
- «Агенти КіберЩиту» просять ім'я та клас для посвідчення, але вони живуть лише в пам'яті сторінки, у `localStorage` не записуються (під час збереження поля `name` і `cls` виключаються) і нікуди не надсилаються. Після перезавантаження їх треба ввести знову.
- Аналітики й трекерів у коді немає. Сайт не робить запитів на сторонні сервери: Blockly лежить у `vendor/`, шрифти (Nunito, Unbounded, Caveat, JetBrains Mono, ліцензія SIL OFL) у `assets/fonts/`.

## SEO

- У `<head>` кожної сторінки: `<title>` у форматі «Назва — Geek Informatic», `description`, `canonical` (абсолютний, з кінцевим `/`), Open Graph (`og:*`, `og:image` на `assets/og/<slug>.png`, 1200x630), `twitter:card` і JSON-LD (`WebSite` + `ItemList` на головній, `LearningResource` на активностях).
- Картинки `assets/og/` генерує `tools/og/make.py` із шаблону `tools/og/tpl.html` (фон-зошит, шрифти й кольори сайту, логотип, назва, підзаголовок) через Chrome headless. Нова активність = новий рядок у списку `pages` у `make.py`, потім:

```
python3 tools/og/make.py            # усі картинки
python3 tools/og/make.py robot      # лише одна
```

  Перевір розмір (`sips -g pixelWidth -g pixelHeight`), PNG має бути до 200 КБ.
- **Додаючи сторінку, оновлюй `sitemap.xml`** (абсолютна адреса з кінцевим `/`, `lastmod`).
- `robots.txt` не створюється: для project page (`/geek-informatic/`) пошукові системи читають його лише з кореня домену `otianoleksij.github.io`, тож тут він не діє. Sitemap треба подати в Google Search Console вручну (властивість `https://otianoleksij.github.io/geek-informatic/`, розділ «Sitemaps», адреса `sitemap.xml`).
- `404.html` віддається GitHub Pages для будь-якого неіснуючого шляху будь-якої глибини, тому в ньому всі посилання й шлях до шрифтів абсолютні (`/geek-informatic/...`). Не міняй їх на відносні.

## Публікація на GitHub Pages

1. Запуш репозиторій `geek-informatic` на GitHub.
2. Settings -> Pages -> Source: **Deploy from a branch**, гілка `main`, папка `/ (root)`.
3. Сайт буде за адресою `https://<логін>.github.io/geek-informatic/`.
