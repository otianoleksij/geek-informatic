Privacy

Updated 22 November 2026

In short: Geek Informatic doesn’t know who you are. There are no accounts, no sign-up and no server that would collect student data.

What the site doesn’t have

  • Accounts, passwords or sign-in.
  • Its own server: nothing is sent anywhere.
  • Analytics, advertising trackers or cookies.
  • Requests to other servers: the fonts and the Blockly library (the block editor) are hosted on the site itself.

Where your progress lives

So that a game remembers where you stopped, the site saves progress in localStorage: a small memory built into the browser. The data stays on this device only and is never transmitted. If you open the site on another computer or in another browser, your progress won’t be there.

What each activity remembers:

  • Drive the Robot!: stars for the levels you have completed.
  • Galaxy Code: stars for levels, the current level, your block programs for each level and the run speed.
  • Mars Rover Maze: your block program, the speed and a mark that the algorithm has already passed the check.
  • 100 rebuses: the numbers of the rebuses you have solved.
  • 50 matchstick puzzles: the numbers of the puzzles you have solved.
  • Space Typing Trainer: stars and best results (accuracy, speed, combo) for the finished levels, separately for the Ukrainian and English layouts.
  • Cyber Shield Agents: which missions are done, points, the mission and screen where you stopped, start and finish times and the key letters.
  • Home page: a short summary of “done out of total” for each activity, used to show the progress bars on the cards.

Name and grade in CyberShield

The quest asks for a name and grade only for the agent ID card. They exist only in the memory of the open page: they are not saved to the device and not sent anywhere. After you reload the page you need to enter them again.

A shared computer at school

Everyone who uses this same browser on this computer can see the progress and programs saved here. If you work on a school computer, clear the data with the button below at the end of the lesson.

Clear my data

The button deletes all Geek Informatic progress in this browser: every activity and the summary on the home page. It can’t be undone.

Hosting

The site is hosted on GitHub Pages. Like any host, GitHub may log technical data about visits (for example, the IP address) under its own rules. We don’t receive or control this data. More: GitHub’s privacy statement.

Questions

Have a question about privacy? Write in the Issues section of the GitHub repository.
